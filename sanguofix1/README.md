# สามก๊กกลยุทธ์ ออนไลน์

เล่นผ่านเว็บ 2–10 คน (ผู้เล่นจริง + บอตเติมที่นั่ง) ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ใช้ Node.js ล้วน ต้องการ Node 18 ขึ้นไป)

## เปิดเล่นบนเครื่องตัวเอง
```
cd sanguo
node server/server.js        # เปิด http://localhost:3000
```
เพื่อนในวง Wi-Fi เดียวกันเข้าด้วย http://<IP เครื่องคุณ>:3000 แล้วสร้างห้อง แชร์รหัสห้อง เพิ่มบอตและกดเริ่ม

## เปิดให้เล่นผ่านอินเทอร์เน็ต
อัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้วสร้าง Web Service บน Render / Railway / Fly.io
- Build command: เว้นว่าง   Start command: `node server/server.js`
- ระบบอ่านพอร์ตจากตัวแปร `PORT` อัตโนมัติ
- สถานะห้องเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ทห้องจะหาย (แผนฟรีมักหลับเมื่อไม่มีคนใช้)

## แก้ข้อมูลไพ่/ขุนศึก
- `shared/data.js` รายการไพ่ 108 ใบ (ชนิด/สัญลักษณ์/เลข), ตารางบทบาท, ขุนศึก 27 คน
- ลอจิกไพ่และทักษะ: `server/engine.js`, `server/engine_cards.js`  บอต: `server/bot.js`
- รูปไพ่: `public/img/cards/<ชนิด>.jpg` รูปขุนศึก: `public/img/heroes/<id>.jpg` เปลี่ยนเป็นไฟล์ของคุณได้โดยใช้ชื่อไฟล์เดิม
- ทดสอบบอตเล่นกันเอง: `node test/sim.js 100`

## ข้อควรตรวจกับของจริง (อ่านจากภาพถ่ายการ์ด)
1. สัญลักษณ์และเลขมุมการ์ดบางใบอ่านจากภาพถ่ายเล็ก อาจคลาดเคลื่อน มีผลเฉพาะไพ่ตัดสิน (แก้ในตาราง RAW ใน `shared/data.js`)
2. ทักษะที่ข้อความบนการ์ดกำกวมตีความดังนี้
   - บังทอง "กลลูกโซ่": ทิ้งไพ่แดงเพื่อแอบดูไพ่ในมือ (ไม่ทำการสลับไพ่)
   - เจินสี "แล้วแต่สวรรค์": ไพ่ที่จั่วทุกใบขึ้นมือ จบเมื่อได้ไพ่แดง
   - ดาบอัคคี: เป้าหมายเลือกเสียพลังชีวิต 1 หรือทิ้งไพ่ 2
   - กระบี่อัสนี: ผู้โจมตีเลือกจั่ว 1 หรือทำลายไพ่ในมือเป้าหมาย 1
3. ชื่อ "เจินสี" "ก้านหลง" "ฮัวฮิ้ง" ถอดจากตัวอักษรบนการ์ดที่เล็ก แก้ใน `shared/data.js` ได้
4. ไพ่ในกองที่ถ่ายมามี 109 ใบ ตัดโจมตีซ้ำ 1 ใบให้เหลือ 108 ตามกติกา
